# Story 1.6: Home Screen Dashboard

**Epic:** 1 - Foundation & Core Loop Setup
**Story Points:** 8
**Status:** ✅ Complete (2025-11-26)
**Version:** 2.0

## User Story

**As a** User,
**I want** to see my generated Home Avatar, progress rings, training cartridge, tab bar, and fitness stats on the Home Screen,
**so that** the main application hub is functional and displays my personal progress and stats.

## Acceptance Criteria

1. [x] The Home Screen UI is implemented following the Game Boy aesthetic (NFR6), displaying content within the virtual LCD area using the DMG palette, and stats on the shell area using the Hardware palette
2. [x] The user's generated Home Avatar is displayed prominently (top-center) within the virtual screen
3. [x] **Dual Progress Rings**, a **Momentum Bar** (NOT streak), and the **"Training Cartridge" button** are displayed below the avatar
4. [x] The **bottom Tab Bar** (Home, Battle, Profile, Settings) is displayed and functional (navigates to placeholder screens)
5. [x] Key fitness stats (Steps, Calories, Workout Duration) are displayed on the **shell area** below the virtual screen
6. [x] Avatar displays appropriate pose based on last battle outcome (victory pose or training pose)
7. [x] Evolution overlay triggers if XP threshold met (Pokemon Red/Blue-style blinking animation)

> ⚠️ **Party Mode Decision (2025-12-29):** Home Dashboard shows **user's personal stats and XP only**. The selected champion is only relevant in Battle Mode context. User's personal stats translate to champion power in battles.

### Post-Battle Avatar States

| Battle Outcome | Avatar State | Message |
|----------------|--------------|---------|
| `victory` | Victory pose (arms raised) | Stats gained displayed |
| `continue_training` | Determined pose (training stance) | "Your champion is resting... time to train more!" |

> **No-Defeat Philosophy:** XP is never removed, stats are never reduced. Avatar never shows disappointed/defeated pose.

## Avatar Integration (Story 1.5 Dependency)

### Avatar Source Architecture

The Home Avatar displayed on this screen is generated via the **"Smooth-to-Pixel" pipeline** defined in Story 1.5. The integration flow is:

```
Story 1.5 (Avatar Generation)     Story 1.6 (Home Screen)
┌─────────────────────────┐      ┌─────────────────────────┐
│ 1. User uploads selfie  │      │                         │
│ 2. AI generates 2       │      │                         │
│    variants (Accuracy,  │      │                         │
│    Retro)               │      │                         │
│ 3. User selects via     │──────│ Display final avatar    │
│    "Draft Pick" UI      │      │ from user_profiles.     │
│ 4. Selected variant     │      │ home_avatar_url         │
│    saved to:            │      │                         │
│    - avatars.final_url  │      │                         │
│    - user_profiles.     │      │                         │
│      home_avatar_url    │      │                         │
└─────────────────────────┘      └─────────────────────────┘
```

### Avatar Data Sources

| Source | Field | Usage |
|--------|-------|-------|
| `user_profiles` | `home_avatar_url` | **Primary** - Use this for display |
| `avatars` | `final_url` | Canonical source (copied to user_profiles after selection) |
| `avatars` | `url_accuracy` | High-likeness variant (available if user wants to switch) |
| `avatars` | `url_retro` | High-style variant (available if user wants to switch) |

### Avatar Display Requirements

1. **Resolution:** 128×128 pixels (exact, no scaling artifacts)
2. **Colors:** Exactly 4 DMG palette colors (guaranteed by Story 1.5 pipeline)
3. **Rendering:** Use `Image` component with `resizeMode="nearest"` to preserve pixel crispness
4. **Fallback:** If `home_avatar_url` is null, display archetype-based placeholder sprite

### HomeAvatar Component

```typescript
// components/molecules/HomeAvatar/index.tsx
interface HomeAvatarProps {
  avatarUrl: string | null;
  archetype: 'trainer' | 'runner' | 'yoga' | 'bodybuilder' | 'cyclist';
  evolutionStage: number;
  pose: 'victory' | 'training' | 'idle'; // Post-battle state
}

const HomeAvatar = ({ avatarUrl, archetype, evolutionStage, pose }: HomeAvatarProps) => {
  // Fallback to archetype placeholder if no avatar generated
  const imageSource = avatarUrl
    ? { uri: avatarUrl }
    : ARCHETYPE_PLACEHOLDERS[archetype];

  return (
    <View style={styles.container}>
      <Image
        source={imageSource}
        style={styles.avatar}
        resizeMode="nearest"  // CRITICAL: Preserves pixel art crispness
      />
      <EvolutionBadge stage={evolutionStage} />
      {pose === 'victory' && <VictoryGlow />}
    </View>
  );
};

const styles = StyleSheet.create({
  avatar: {
    width: 128,
    height: 128,
    // Ensure no anti-aliasing or smoothing
    imageRendering: 'pixelated',
  },
});
```

## Momentum System (NOT Streak)

> **Party Mode Decision:** Replace punitive streak system with graceful decay momentum.

| Behavior | Old (Streak) | New (Momentum) |
|----------|--------------|----------------|
| Miss 1 day | Reset to 0 | 5% decay |
| Display | "0 day streak" | "47 days momentum" |
| Messaging | "You broke your streak!" | None (no guilt) |
| System | Binary (on/off) | Graceful gradient |

```typescript
const calculateMomentum = (currentMomentum: number, missedDays: number): number => {
  const decayRate = 0.05; // 5% per missed day
  const decayMultiplier = Math.pow(1 - decayRate, missedDays);
  return Math.round(currentMomentum * decayMultiplier);
};
// Example: 100 days momentum + 1 missed day = 95 days (NOT 0)
```
