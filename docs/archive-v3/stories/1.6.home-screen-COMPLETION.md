## 🔴 BLOCKER #2: Silent RLS Failure for Deferred Users

### Problem
**Symptom:** Database update appeared to succeed but didn't modify any rows.

**Root Cause:** Row Level Security (RLS) blocked deferred (guest) users from updating profiles. Supabase returned `data: []` instead of throwing an error.

**Console Evidence:**
```
[CharacterSelection] Auth Status: deferred
[CharacterSelection] Update response - Data: []  ← Empty = RLS blocked
[CharacterSelection] Update response - Error: null  ← No error thrown
```

### Solution
Created RLS policy for deferred users:

**File:** [20251125220000_fix_deferred_rls.sql](file:///Users/seanwinslow/.gemini/antigravity/scratch/16BitFit-V3/supabase/migrations/20251125220000_fix_deferred_rls.sql)

```sql
CREATE POLICY "Users can update own profile"
ON public.user_profiles
FOR UPDATE
USING (
  -- Allow update if auth.uid matches (Authenticated)
  auth.uid() = id
  OR
  -- Allow update if user is deferred (Guest) and ID matches
  (auth.uid() IS NULL AND auth_status = 'deferred')
);
```

Added silent failure detection:

```typescript
const { data, error } = await supabase
  .from('user_profiles')
  .update(updatePayload)
  .eq('id', userId)
  .select();

if (error) throw error;

// ✅ Detect silent RLS failure
if (!data || data.length === 0) {
  throw new Error('Update failed: No rows modified. RLS policy may be blocking deferred user.');
}
```

## 🔴 BLOCKER #4: RootNavigator Implementation

### Problem
**Symptom:** `RootNavigator` didn't exist yet - it was just a placeholder tab navigator.

### Solution
Created smart `RootNavigator` that:
1. Checks user's `onboarding_completed` status
2. Supports both authenticated and deferred users
3. Listens for real-time profile updates
4. Shows loading state while checking status

**File:** [apps/mobile-shell/src/navigation/index.tsx](file:///Users/seanwinslow/.gemini/antigravity/scratch/16BitFit-V3/apps/mobile-shell/src/navigation/index.tsx)

```typescript
export const RootNavigator: React.FC = () => {
  const { user, deferredProfile } = useAuthStore();
  const [isOnboardingCompleted, setIsOnboardingCompleted] = useState<boolean | null>(null);

  useEffect(() => {
    const checkOnboardingStatus = async () => {
      const userId = user?.id || deferredProfile?.id;
      if (!userId) {
        setIsOnboardingCompleted(false);
        return;
      }

      const { data, error } = await supabase
        .from('user_profiles')
        .select('onboarding_completed')
        .eq('id', userId)
        .single();

      if (error) {
        console.error('Error checking onboarding status:', error);
        setIsOnboardingCompleted(false);
      } else {
        setIsOnboardingCompleted(data?.onboarding_completed || false);
      }
    };

    checkOnboardingStatus();

    // Real-time subscription for profile updates
    const userId = user?.id || deferredProfile?.id;
    if (userId) {
      const subscription = supabase
        .channel(`public:user_profiles:id=eq.${userId}`)
        .on('postgres_changes', {
          event: 'UPDATE',
          schema: 'public',
          table: 'user_profiles',
          filter: `id=eq.${userId}`,
        }, (payload) => {
          if (payload.new && 'onboarding_completed' in payload.new) {
            setIsOnboardingCompleted(payload.new.onboarding_completed);
          }
        })
        .subscribe();

      return () => { supabase.removeChannel(subscription); };
    }
  }, [user, deferredProfile]);

  if (isOnboardingCompleted === null) {
    return <LoadingScreen />;
  }

  return (
    <NavigationContainer>
      {isOnboardingCompleted ? <MainTabNavigator /> : <OnboardingNavigator />}
    </NavigationContainer>
  );
};
```

```typescript
import React from 'react';
import Svg, { Circle, G } from 'react-native-svg';

const ProgressRing: React.FC<ProgressRingProps> = ({
  progress,
  size = 100,
  strokeWidth = 10,
  label,
  color = colors.dmg.dark,
}) => {
  const radius = (size - strokeWidth) / 2;
  const circumference = radius * 2 * Math.PI;
  const strokeDashoffset = circumference - progress * circumference;

  return (
    <View style={[styles.container, { width: size, height: size }]}>
      <Svg width={size} height={size}>
        <G rotation="-90" origin={`${size / 2}, ${size / 2}`}>
          <Circle
            cx={size / 2}
            cy={size / 2}
            r={radius}
            stroke={colors.dmg.light}
            strokeWidth={strokeWidth}
            fill="transparent"
          />
          <Circle
            cx={size / 2}
            cy={size / 2}
            r={radius}
            stroke={color}
            strokeWidth={strokeWidth}
            fill="transparent"
            strokeDasharray={circumference}
            strokeDashoffset={strokeDashoffset}
            strokeLinecap="round"
          />
        </G>
      </Svg>
      {label && (
        <View style={styles.labelContainer}>
          <PixelText variant="caption">{label}</PixelText>
          <PixelText variant="body">{Math.round(progress * 100)}%</PixelText>
        </View>
      )}
    </View>
  );
};
```

## 🔴 BLOCKER #6: Home Screen Stuck on "Loading..."

### Problem
**Symptom:** After successfully navigating to Home Screen, it displayed "Loading..." forever.

![Loading Screen Stuck](/Users/seanwinslow/.gemini/antigravity/brain/966c3908-1162-49f0-8a71-00b58ac51c26/uploaded_image_1764153519844.png)

**Root Cause:** HomeScreen only checked `user.id`, which is `null` for deferred users. The profile fetch never started.

**Original Code:**
```typescript
// ❌ WRONG - Ignores deferred users
const { user } = useAuthStore();

const fetchProfile = async () => {
  if (!user?.id) return; // Early return for deferred users!
  
  const { data, error } = await supabase
    .from('user_profiles')
    .select('*')
    .eq('id', user.id)
    .single();
  
  setProfile(data);
  setLoading(false);
};
```

### Solution
Check both `user` and `deferredProfile`:

```typescript
// ✅ CORRECT - Supports deferred users
const { user, deferredProfile } = useAuthStore();

const fetchProfile = async () => {
  const userId = user?.id || deferredProfile?.id;
  if (!userId) {
    setLoading(false);
    return;
  }

  const { data, error } = await supabase
    .from('user_profiles')
    .select('*')
    .eq('id', userId)
    .single();

  setProfile(data);
  setLoading(false);
};

useEffect(() => {
  fetchProfile();
}, [user, deferredProfile]); // Watch both!
```

## Lessons Learned for Future Agents

### Critical Debugging Patterns

1. **Always check both user AND deferredProfile**
   ```typescript
   const userId = user?.id || deferredProfile?.id;
   ```

2. **Verify RLS doesn't silently fail**
   ```typescript
   const { data, error } = await supabase
     .from('user_profiles')
     .update(payload)
     .eq('id', userId)
     .select(); // CRITICAL: Use .select() to verify rows returned
   
   if (!data || data.length === 0) {
     throw new Error('Silent RLS failure');
   }
   ```

3. **Type mismatches fail silently in Supabase**
   - Always verify database schema matches API calls
   - Use `.select()` to see what was actually written

4. **Clear Metro cache when navigation seems broken**
   ```bash
   npx expo start -c
   ```

5. **Check App.tsx navigation wiring**
   - Ensure `RootNavigator` is used, not hardcoded navigators

### File Checklist for Navigation Bugs

When "confirm button does nothing":
1. ✅ Check database update returns data
2. ✅ Check RLS policies allow the operation
3. ✅ Verify App.tsx uses RootNavigator
4. ✅ Confirm RootNavigator checks onboarding_completed
5. ✅ Ensure component handles both user types
