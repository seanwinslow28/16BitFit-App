# Story 1.10: Basic FTUE & Tutorial Battle Integration

**Epic:** 1 - Foundation & Core Loop Setup
**Story Points:** 8
**Status:** ⏳ Pending
**Version:** 2.0

## User Story

**As a** New User,
**I want** the onboarding flow (including a simulated workout) to conclude with a brief tutorial battle against the Training Dummy, followed by landing on the Home Dashboard with my avatar showing a victory pose,
**so that** I understand the core loop and controls within 60-90 seconds.

## Acceptance Criteria

1. [ ] The onboarding flow (Welcome → Archetype Selection → Tutorial Training Assignment → Simulated Workout) transitions smoothly into the tutorial battle
2. [ ] The tutorial briefly explains basic movement and attack controls
3. [ ] The tutorial initiates the first battle via the **Battle Mode Transition Video** (portrait → landscape)
4. [ ] **Tutorial battle GUARANTEES VICTORY** - user cannot fail their first experience
5. [ ] Battle results are applied silently; avatar displays victory pose on Home Dashboard
6. [ ] The entire FTUE (including tutorial battle) aims to be completable within 60-90 seconds (NFR11)

> ⚠️ **Party Mode Decisions (2025-12-29):**
> - **No Combat Character Selection in FTUE** - User gets default champion (Sean) for tutorial
> - **Victory Ceremony is DEPRECATED** - Results shown via avatar pose on Home Dashboard
> - **No-Defeat Philosophy** - Tutorial battle always results in victory
> - Champion selection unlocked in Battle Mode AFTER completing FTUE

## FTUE Flow ("Hook-First" Strategy)

```
1. Welcome Screen (5s)
   ↓
2. Archetype Selection (15s) ● ○ ○
   ↓
3. Tutorial Training Assignment (5s) ● ● ○
   ↓
4. Simulated Workout (15-20s, skip after 10s)
   ↓
5. Battle Mode Transition Video (3-5s) [portrait → landscape]
   ↓
6. Tutorial Battle (30-45s) [Phaser, Landscape]   ← This Story
   • Default champion: Sean
   • GUARANTEED VICTORY
   ↓
7. Battle Mode Transition Video (3-5s) [landscape → portrait]
   ↓
8. Home Dashboard (avatar shows VICTORY POSE)    ← This Story
   • Evolution overlay if XP threshold met
```

**Total Target Time:** 60-90 seconds (Core loop complete!)

> [!IMPORTANT]
> **Progressive Disclosure:** Account Creation, Avatar Generation, Health Connect, and **Champion Selection** are **DEFERRED** until after the user reaches the Home Dashboard.

| **Battle Mode Transition Video** | Entering/Exiting Battle Mode (portrait ↔ landscape) | ~3-5 sec |

> ⚠️ **Do NOT use Cartridge Load Animation in FTUE** - reserved for post-onboarding real workout entry.

### Tutorial Battle

**Phaser Scene: TutorialBattleScene**

```typescript
export class TutorialBattleScene extends BattleScene {
  create() {
    super.create();

    // CRITICAL: Use default champion (Sean) for tutorial
    this.loadChampion('sean');

    // Make training dummy extremely passive - GUARANTEED VICTORY
    this.dummy.setPassive(true);
    this.dummy.setHealth(30); // Low HP, defeated in 3 hits

    // Disable timer for tutorial
    this.timer.pause();

    // Enable tutorial hints
    this.enableTutorialMode();
  }

  private enableTutorialMode(): void {
    // Show hit markers
    // Slow down game speed slightly
    // Provide hints after inactivity

    this.time.addEvent({
      delay: 5000,
      callback: () => {
        if (this.playerHitCount === 0) {
          this.showHint('Try using Light Punch!');
        }
      },
    });
  }

  onVictory(): void {
    // GUARANTEED VICTORY - Tutorial battle cannot fail
    // Send results to React Native (no ceremony scene)
    bridge.send('TUTORIAL_COMPLETE', {
      outcome: 'victory', // Always victory for tutorial
      xpGained: 50,
      coinsGained: 10,
      unlockedBattleMode: true,
    });
  }
}
```

> ⚠️ **GUARANTEED VICTORY:** Tutorial dummy has minimal HP (3 hits to defeat), is completely passive, and the battle cannot time out. This ensures a positive first experience.

### Return to Home Dashboard (NO Victory Ceremony)

**File:** `apps/mobile-shell/src/screens/HomeScreen.tsx`

```typescript
// Listen for tutorial completion
useEffect(() => {
  const unsubscribe = bridge.on('TUTORIAL_COMPLETE', (data) => {
    // Mark onboarding as complete
    setOnboardingComplete(true);

    // Apply rewards silently
    applyRewards(data.xpGained, data.coinsGained);

    // Avatar will display VICTORY POSE based on battle outcome
    setLastBattleOutcome('victory');

    // Check for evolution trigger
    if (shouldEvolve(newXP)) {
      triggerEvolutionOverlay();
    }

    // Update user profile in Supabase
    supabase
      .from('user_profiles')
      .update({ 
        onboarding_completed: true,
        tutorial_completed: true,
        tutorial_completed_at: new Date().toISOString(),
        last_battle_outcome: 'victory',
      })
      .eq('id', userId);
  });

  return unsubscribe;
}, []);
```

> ⚠️ **Victory Ceremony DEPRECATED:** No standalone ceremony screen. Battle results are:
> 1. Applied silently to user stats
> 2. Reflected in avatar pose on Home Dashboard (victory pose)
> 3. Evolution overlay triggered if XP threshold met

## Post-Tutorial: Champion Selection Unlocked

After completing FTUE and landing on Home Dashboard, the user can:

1. Tap **Battle** tab in bottom navigation
2. Access **"Choose Your Champion"** menu option
3. Select from 6 champions in SF2-style 2×3 grid (Phaser, landscape)
4. All champions are **purely cosmetic** (Mario Party model - identical stats)

- Sean (MMA) - Default during tutorial

- Marcus (Boxer)
