# Story 1.4: Onboarding Flow - Archetype Selection

**Epic:** 1 - Foundation & Core Loop Setup
**Story Points:** 5
**Status:** ✅ Complete (Updated for Hook-First Strategy + Party Mode)
**Version:** 2.0

## User Story

**As a** New User,
**I want** to select my desired Fitness Archetype (Trainer, Runner, Yoga, Bodybuilder, Cyclist) immediately after the Welcome screen,
**so that** I can begin personalizing my experience without the friction of account creation.

## Acceptance Criteria

1. [x] **Archetype Selection Screen** is presented immediately after the Welcome Screen.
2. [x] User is presented with the five Fitness Archetype options (Trainer, Runner, Yoga, Bodybuilder, Cyclist).
3. [x] User selection is saved **locally** (AsyncStorage/MMKV) initially, not requiring an account.
4. [x] The flow transitions smoothly to **Tutorial Training Assignment** upon confirmation.
5. [x] "Profile Setup" (Account Creation) is **removed** from this initial flow and deferred to Phase 2 (Home Screen trigger).
6. [x] Default champion (Sean) is automatically assigned for tutorial battle.

> ⚠️ **Party Mode Decision (2025-12-29):** Champion selection happens in **Battle Mode** (Phaser, landscape) with SF2-style 2×3 grid—**NOT during onboarding**. User gets default champion (Sean) for tutorial.

## User Flow Diagram

```
Welcome Screen
     ↓
Archetype Selection (● ○ ○ - Step 1/3)
     ↓
Tutorial Training Assignment (● ● ○ - Step 2/3)
     ↓
Simulated Workout (60s, skippable after 10s)
     ↓
Battle Mode Transition Video (portrait → landscape)
     ↓
Tutorial Battle (default champion: Sean, GUARANTEED VICTORY)
     ↓
Battle Mode Transition Video (landscape → portrait)
     ↓
Home Dashboard (avatar shows victory pose)
```

> **Note:** Champion selection is unlocked in Battle Mode AFTER completing FTUE. See `user-flow-diagram.md` for full flow details.

## Progress Dots Pattern

| Screen | Progress Dots | Rationale |
|--------|---------------|-----------|
| Welcome Screen | **NONE** | Clean "PRESS START" moment |
| Archetype Selection | **● ○ ○** (1/3) | First decision: Choose identity |
| Tutorial Training Assignment | **● ● ○** (2/3) | Second decision: Commit to workout |
| Simulated Workout | **NONE** | Exercise progress shown separately |
| Battle Mode screens | **NONE** | Different context (Phaser, landscape) |
| Home Dashboard | **NONE** | Onboarding complete! |
