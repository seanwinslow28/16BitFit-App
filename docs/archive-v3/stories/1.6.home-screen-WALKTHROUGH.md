## Major Blockers Encountered & Resolved

### 🔴 Blocker #1: Type Mismatch
**Symptom:** Button did nothing after character selection  
**Cause:** Sent string `'stage_1'` to INTEGER column  
**Fix:** Changed to integer `1`

### 🔴 Blocker #2: Silent RLS Failure
**Symptom:** Update appeared to succeed but didn't modify rows  
**Cause:** RLS blocked deferred users, returned empty array instead of error  
**Fix:** Created RLS policy + added `.select()` verification

### 🔴 Blocker #3: Hardcoded Navigator
**Symptom:** App never left onboarding  
**Cause:** App.tsx hardcoded `OnboardingNavigator`  
**Fix:** Replaced with `RootNavigator`

### 🔴 Blocker #4: Missing Navigation Logic
**Symptom:** No conditional routing  
**Cause:** RootNavigator was just a placeholder tab nav  
**Fix:** Implemented smart RootNavigator with status checking

### 🔴 Blocker #5: Build Errors
**Symptoms:** NavigationContainer errors, missing modules, Skia issues  
**Fixes:**
- Cleared Metro cache (`npx expo start -c`)
- Disabled Skia in DiagnosticScreen
- Fixed HomeScreen import path
- Created missing ProgressRing component

### 🔴 Blocker #6: Loading Screen Stuck
**Symptom:** Home Screen showed "Loading..." forever  
**Cause:** Only checked `user.id`, ignored `deferredProfile.id`  
**Fix:** Updated to check both user types

## Lessons Learned for Future Agents

### 1. Always Support Both User Types

```typescript
// ✅ CORRECT
const userId = user?.id || deferredProfile?.id;
```

### 2. Verify RLS Doesn't Silently Fail

```typescript
// ✅ CORRECT
const { data, error } = await supabase
  .from('user_profiles')
  .update(payload)
  .eq('id', userId)
  .select(); // Add .select() to verify rows returned

if (!data || data.length === 0) {
  throw new Error('Silent RLS failure');
}
```

### 3. Type Mismatches Fail Silently

Always verify database schema matches TypeScript types:
- Database: `INTEGER`
- Code: Must send `number`, not `string`

### 4. Clear Metro Cache for Navigation Issues

```bash
npx expo start -c
```

### 5. Check App.tsx Navigation Wiring

Ensure `RootNavigator` is used, not hardcoded navigators.

### 6. RLS Policies for Deferred Users

```sql
USING (
  auth.uid() = id OR
  (auth.uid() IS NULL AND auth_status = 'deferred')
);
```
